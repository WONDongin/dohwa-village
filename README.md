# 🌸 도화마을

> 오늘도 현실에서 수고했습니다. 여기서는 잠깐 쓸모없는 일을 해도 괜찮아요.

**도화마을**은 2D 도트 마을을 돌아다니며 작은 놀이를 즐기는 온라인 놀이터입니다. <br>
마을을 중심으로 돌멩이 키우기, 기분 우체국, 오늘의 소원 동전을 한 서비스에서 개발합니다.

## 📌 핵심 기능

| 기능 | 예정 경로 | 기획 범위 |
| --- | --- | --- |
| 마을 메인 | `/` | 도트 마을을 탐색하고 각 콘텐츠에 입장합니다. 캐릭터 이동과 건물 진입 연출을 계획하고 있습니다. |
| 돌멩이 키우기 | `/stone` | 돌을 만들고 쓰다듬기·씻기·물주기·꾸미기를 통해 돌을 키웁니다. |
| 기분 우체국 | `/post-office` | 행복한 기억과 속상한 기억을 남기고 다른 글에 반응합니다. |
| 오늘의 소원 동전 | `/wish-coin` | 하루에 한 번 동전을 던지고 앞면·뒷면에 따라 메시지를 확인합니다. |

<br>

## 📌 서비스 구조

프론트엔드와 백엔드는 한 저장소에서 관리합니다. 마을 메인에서 세 콘텐츠로 이동하고, 각 콘텐츠에서 마을로 돌아오는 동선을 기준으로 화면을 나눕니다.

| 경로 | 역할 |
| --- | --- |
| [`frontend/`](frontend/) | 마을 메인과 콘텐츠 화면, 라우팅, 화면 상호작용 |
| [`backend/`](backend/) | 저장과 서버 검증이 필요한 기능의 API 및 데이터 처리 |

현재 두 디렉토리는 `.gitkeep`으로 유지하고 있습니다. 앱 초기화 후 프론트엔드 화면과 백엔드 패키지를 기능별로 구성합니다.

<br>

## 📌 주요 설계

### 1. 돌멩이 저장과 일일 보상

- **게스트·회원 저장** — 게스트의 돌 상태는 브라우저에, 회원의 돌 상태는 서버에 저장하도록 설계했습니다. 가입 시 이름과 기본 꾸미기 정보를 이전하는 흐름을 포함합니다.
- **일일 보상** — 같은 돌봄 행동의 보상은 하루에 한 번만 지급하도록 설계했습니다. DB 유일 제약과 트랜잭션으로 동시 요청을 처리하고, 같은 요청이 재전송되면 기존 처리 결과를 반환하는 방향입니다.

### 2. 기분 우체국 운영 흐름

- **비회원 참여** — 가입 없이 닉네임으로 글을 작성하고, 본인 글을 수정하거나 삭제할 수 있도록 기획했습니다.
- **게시글 초기화** — 게시글을 주 단위로 초기화하는 운영 방식을 계획하고 있습니다.

## 📌 개발 순서

1. **공통 작업** — 프론트엔드·백엔드를 초기화하고 마을 메인에서 각 콘텐츠 화면으로 들어갔다가 돌아오는 경로를 연결합니다.
2. **병렬 개발** — 동인님은 돌멩이 키우기의 게스트 저장·복원부터, 협업자는 기분 우체국의 목록·글쓰기·반응부터 개발합니다.
3. **소원 동전 및 통합** — 소원 동전을 연결하고 마을 이동과 모바일 화면을 확인합니다.
