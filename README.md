## 📌 서비스 구성

| 콘텐츠 | 예정 경로 | 핵심 기능 |
| --- | --- | --- |

## 📌 이용 방식

- **마을 탐색** — 캐릭터가 등장하면 방향키·클릭·터치로 이동합니다. 건물이나 분수에 접근하거나 바로가기 메뉴에서 콘텐츠에 들어갑니다.
- **비회원** — 우체국과 소원 동전을 이용할 수 있고, 돌멩이 상태는 현재 브라우저에 저장합니다.
- **회원** — 돌멩이 진행 상황을 계정에 저장해 다른 기기에서도 이어서 키울 수 있습니다.

## 📌 기분 우체국

**행복한 기억은 나누고, 속상한 마음은 털어내는 감정 공유 공간**

### 게시판과 불운 분리수거

| 기능 | 이용 방식 |
| --- | --- |
| 행복한 기억 | 행복했던 순간을 공개하고 다른 사람의 글에 좋아요를 남깁니다. 작성일과 최신순·인기순 정렬을 제공합니다. |
| 속상한 기억 | 속상했던 일을 공개하고 다른 사람의 글에 공감합니다. 작성일과 최신순·공감순 정렬을 제공하며 댓글은 제공하지 않습니다. |
| 불운 분리수거 | 글자 수를 확인하며 내용을 입력하고, `버리기`를 누르면 종이가 구겨져 쓰레기통에 들어갑니다. 위로 메시지를 표시한 뒤 입력을 지웁니다. 입력 내용은 서버에 전송하거나 저장하지 않으며 버린 뒤에는 복구할 수 없습니다. |

두 게시판의 기본 목록에는 이번 주에 작성한 공개 글만 표시합니다.

### 비회원 글쓰기와 작성자 확인

- 가입 없이 닉네임과 내용으로 작성합니다. 당일 첫 참여 시 닉네임을 정하고 같은 날 재접속하면 브라우저에 저장된 닉네임을 사용합니다. 한국 시간 자정이 지난 뒤 참여할 때 다시 설정합니다.
- 닉네임은 **2~10자, 중복 허용**을 기본안으로 두고, 글에는 작성 당시 닉네임을 보존합니다.
- 서버는 비회원 식별자를 발급해 **HttpOnly 쿠키**로 전달합니다. 작성자 확인과 중복 공감·신고 판정에는 이 식별자를 사용합니다. 쿠키를 삭제하거나 다른 기기·브라우저를 사용하면 기존 글의 작성자 확인과 이용자 단위의 중복 방지에 한계가 있습니다.

### 주간 초기화·베스트·통계

- 한 주는 **한국 시간 월요일 00시부터 다음 월요일 00시 전까지**입니다. 이번 주 공개 글만 기본 목록에 표시하고 공감할 수 있습니다. 다음 주에 지난주 일반 글을 숨기며, 원본 글의 DB 보관·삭제 기간은 추후 결정합니다.
- 행복한 기억과 속상한 기억에서 각각 공감 수가 가장 많은 글을 선정합니다. 동점이면 먼저 작성한 글을 우선하고, 삭제·운영자 숨김 상태의 글은 제외합니다. 대상이 없으면 ‘베스트글 없음’으로 표시합니다.
- 주간 마감 후 베스트글과 요약 통계를 보관합니다. 전체 글 수, 행복한 글 수, 속상한 글 수, 전체 공감 수를 제공합니다.

### 수정·삭제와 운영 관리

- 본인 글만 수정·삭제할 수 있습니다. 이번 주 글의 내용만 수정할 수 있고, 작성 당시 닉네임을 유지하며 `수정됨`을 표시합니다. 마감된 지난주 글은 수정할 수 없습니다.
- 삭제할 때 확인창을 표시합니다. 본인 글은 지난주 베스트로 공개된 뒤에도 삭제할 수 있습니다. 삭제된 글은 목록과 베스트에서 즉시 숨기고 DB에서는 우선 삭제 상태로 관리합니다.
- 다른 사람의 글은 **욕설·혐오, 광고·도배, 개인정보 노출, 기타** 사유로 신고할 수 있습니다. 같은 식별자의 중복 신고를 막고, 운영자가 확인한 뒤 숨김 여부를 결정합니다. 숨김 글은 목록과 베스트에서 제외합니다.
- 화면에서 내 글에는 수정·삭제를, 다른 글에는 신고 메뉴를 제공합니다. 서버가 작성자 권한과 요청 조건을 검증하고 글 작성·수정·공감·신고의 연속 요청을 제한합니다.

## 📌 애완 돌멩이 키우기

**도화마을에서 돌을 돌보고 꾸미며 쉬어가는 힐링 게임**

| 기능 | 기획 내용 |
| --- | --- |
| 돌 생성 | 이름과 기본 외형을 선택합니다. 회원당 돌을 한 개 보유할 수 있습니다. |
| 돌봄 | 쓰다듬을 때 표정·말풍선·하트로 반응하고, 씻길 때 드래그로 거품을 내며, 물을 주면 물방울과 돌의 반응을 보여줍니다. |
| 성장·꾸미기 | 돌봄으로 경험치를 얻고, 성장 단계에 따라 모자·안경·받침대·배경 등을 해금합니다. |
| 게스트 저장 | 가입 없이 체험하고 현재 브라우저에 저장합니다. **24시간이 지나도 상태를 유지**합니다. 브라우저 데이터를 삭제하면 복구할 수 없습니다. |
| 회원 저장·이전 | 로그인해 다른 기기에서도 이어서 키웁니다. 가입 시 게스트의 이름·기본 외형·기본 꾸미기를 이전합니다. 게스트 경험치는 분리하고, 계정에 돌이 있으면 기존 돌을 유지합니다. |

오래 접속하지 않아도 돌이 죽거나 경험치가 줄어드는 벌점은 없습니다.

### 일일 보상 중복 방지

돌봄은 반복할 수 있고, 경험치는 **행동별 하루 한 번** 지급합니다. 보상 날짜는 서버에서 한국 시간 기준으로 판단합니다. 동시 클릭·여러 탭·요청 재전송에서도 보상과 경험치가 한 번만 반영되도록 트랜잭션, `UNIQUE` 제약, 동시성 제어와 요청 식별 키를 적용할 계획입니다.

### 확장 기능

관찰 일지, 사진 저장, 자연 소리, 정원 3D 미로를 검토합니다. 미로에서는 탈출 시간 측정, 힌트, 재도전과 개인 기록을 계획합니다.

## 📌 오늘의 소원 동전

**마음속으로 소원을 빌고 하루 한 번 동전을 던지는 가벼운 운세 놀이**

- 가입 없이 참여하며 우체국과 같은 비회원 식별자를 사용합니다. 소원은 마음속으로만 빕니다.
- 서버가 참여 가능 여부를 확인하고 앞면과 뒷면을 각각 **50% 확률**로 결정합니다. 저장한 결과를 동전 회전·낙하 애니메이션으로 보여줍니다. 움직임 감소 설정에서는 연출을 줄이고 결과를 표시합니다.
- **한국 시간 자정마다** 참여 기회가 갱신됩니다. 식별자별 하루 1회 참여할 수 있으며 닉네임을 바꿔도 횟수는 유지됩니다. 처리·연출 중에는 중복 클릭을 막고 참여 후에는 버튼을 비활성화해 `오늘의 동전을 던졌어요`를 표시합니다.
- 같은 날 재접속하거나 새로고침해도 결과와 메시지가 유지됩니다. 연출을 건너뛰어도 결과는 같고, 응답이 끊겨 재요청하면 이미 저장한 결과를 반환합니다. 저장 기록이 없으면 다시 시도할 수 있습니다.

| 결과 | 메시지 예시 |
| --- | --- |
| 앞면 | 오늘은 작은 행운이 네 편이에요. |
| 앞면 | 미뤄둔 일을 살짝 시작해봐도 좋겠어요. |
| 뒷면 | 소원이 도착하려면 조금 더 걸리나 봐요. |
| 뒷면 | 오늘의 행운은 쉬어가는 시간에 숨어 있어요. |

양면에 부담 없는 긍정적인 문구를 사용하고 재미로 즐기는 콘텐츠임을 안내합니다.

### 서버 처리와 저장

비회원 식별자·참여 날짜·동전 결과·메시지 코드·참여 시각을 저장합니다. **`비회원 식별자 + 참여 날짜`에 `UNIQUE` 제약**을 적용해 동시 요청에서도 처음 저장한 결과 하나를 사용합니다. 날짜가 바뀌면 새 기록을 만들며, 기존 기록의 보관 기간은 추후 결정합니다. 쿠키를 삭제하거나 브라우저를 바꾸면 새 식별자가 발급돼 당일 다시 참여할 수 있습니다.

## 📌 기술·배포

프론트엔드 1개, 백엔드 1개, PostgreSQL DB 1개로 구성하고 각각 기능 단위로 관리합니다. 현재 저장소의 `frontend/`와 `backend/`는 `.gitkeep`으로 유지하고 있습니다.

| 구분 | 도입·배포 계획 | 역할 |
| --- | --- | --- |
| [프론트엔드](frontend/) | React + Vite / Vercel | 마을 탐색, 콘텐츠 화면, 게시글·공감·통계 화면, 동전·불운 분리수거 연출 |
| [백엔드](backend/) | Java 21 + Spring Boot / Render | 비회원 식별·작성자 확인, 글·공감·신고, 주간 집계, 돌봄 보상·동전 중복 처리 방지 |
| DB | PostgreSQL / Neon | 게시글·비회원 식별 정보·공감·신고·주간 베스트, 회원 돌 상태와 보상·동전 결과 저장 |
