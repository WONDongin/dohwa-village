# 도화마을

> 오늘도 현실에서 수고했습니다. 여기서는 잠깐 쓸모없는 일을 해도 괜찮아요.

도화마을은 2D 도트 마을을 돌아다니며 작은 놀이를 즐기는 온라인 놀이터입니다. 두 명이 함께 개발하며, 프론트엔드와 백엔드를 하나의 Git 저장소에서 관리합니다.

## 주요 기능

| 기능 | 화면 경로 | 계획 |
| --- | --- | --- |
| 마을 메인 | `/` | 마을을 탐색하고 각 콘텐츠에 입장합니다. 첫 작업에서는 입장·복귀 경로를 연결하고, 이후 캐릭터 이동과 입장 연출을 추가합니다. |
| 돌멩이 키우기 | `/stone` | 돌을 만들고 쓰다듬기·씻기·물주기·꾸미기를 할 수 있습니다. 게스트는 브라우저에, 회원은 서버에 저장합니다. 가입 시 게스트 데이터 이전과 일일 보상 중복 방지를 구현할 예정입니다. |
| 기분 우체국 | `/post-office` | 행복한 기억과 속상한 기억을 쓰고 반응을 남깁니다. 비회원 글쓰기, 본인 글 수정·삭제, 게시글 주간 초기화를 계획합니다. |
| 오늘의 소원 동전 | `/wish-coin` | 하루 한 번 동전을 던지고 앞면·뒷면에 따라 오늘의 메시지를 확인합니다. |

## 기술 구성

| 영역 | 기술 |
| --- | --- |
| 프론트엔드 | React, Vite |
| 백엔드 | Java 21, Spring Boot |
| 데이터베이스 | PostgreSQL |
| 배포 예정 | Vercel(프론트엔드), Render(백엔드), Neon(DB) |

## 프로젝트 구조

현재는 저장소 초기화 단계입니다. 아래 기능 경로는 앱을 초기화한 뒤 사용할 예정입니다.

```text
dohwa-village/
├── README.md
├── .gitignore
├── frontend/
│   └── src/features/
│       ├── village/
│       ├── stone/
│       ├── post-office/
│       └── wish-coin/
└── backend/
    └── src/main/java/com/dohwa/
        ├── stone/
        ├── postoffice/
        └── wishcoin/
```

마을 메인은 화면 탐색과 라우팅을 프론트엔드에서 처리합니다. 저장이나 서버 검증이 필요한 기능은 백엔드에 기능별 패키지를 둡니다.

## 개발 순서

1. **공통 작업** — React·Spring Boot 프로젝트를 초기화하고 마을 메인에서 각 콘텐츠 화면에 들어갔다가 돌아올 수 있게 연결합니다.
2. **병렬 개발** — 동인님은 돌멩이 키우기를, 협업자는 기분 우체국을 담당합니다. 돌멩이는 게스트 저장·복원부터, 우체국은 목록·글쓰기·반응부터 연결합니다.
3. **소원 동전 및 통합** — 소원 동전을 연결한 뒤, 마을 진입·복귀와 모바일 화면을 함께 확인합니다.

저장소 루트는 Git과 Codex 작업 기준으로 사용합니다. IntelliJ에서는 백엔드 초기화 후 `backend/`를 엽니다. 실행·테스트 명령은 첫 초기화 PR에서 추가합니다.
